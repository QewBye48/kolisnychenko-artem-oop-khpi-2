# Лабораторна робота №10

## Тема

Узагальнені контейнери та ітератори в Java.

## Варіант

Варіант 5 — ігровий інвентар.

## Мета роботи

Мета роботи — навчитися реалізовувати власний узагальнений контейнер та власний ітератор у Java, а також забезпечити підтримку обходу елементів через `Iterator` і цикл `for-each`.

## Опис предметної області

У роботі реалізовано просту модель ігрового інвентаря.

У моделі є:

- гравець;
- ігровий предмет;
- слот спорядження.

Гравець може мати інвентар, у якому зберігаються предмети. Для зберігання предметів використовується самописний узагальнений контейнер `InventoryContainer<T>`.

## Класи предметної області

### `Player`

Клас описує гравця.

Поля:

- `nickname` — нікнейм гравця;
- `level` — рівень гравця.

### `Item`

Клас описує ігровий предмет.

Поля:

- `name` — назва предмета;
- `slot` — слот спорядження;
- `power` — сила предмета.

### `EquipmentSlot`

Перелік доступних слотів спорядження:

- `WEAPON`;
- `ARMOR`;
- `HELMET`;
- `RING`;
- `POTION`.
