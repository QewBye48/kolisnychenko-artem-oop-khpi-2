# Лабораторна робота №13

## Тема

Обробка тексту і регулярні вирази в Java.

## Варіант

Варіант 5 — інтернет-магазин.

## Суть задачі

Потрібно реалізувати програму для обробки текстових записів інтернет-магазину.

Програма читає записи з файлу `orders.txt`, перевіряє їхній формат, вилучає артикул, назву товару, кількість і ціну, після чого формує підсумковий звіт.

## Що реалізовано

У проєкті реалізовано:

- `ProductOrder` — модель товарного запису;
- `OrderReport` — модель підсумкового звіту;
- `OrderTextProcessor` — сервіс для обробки тексту;
- `Main` — демонстраційний запуск програми;
- `orders.txt` — файл із вхідними даними.

## Формат запису

Коректний запис має вигляд:

```text
ART-1001; Ноутбук Lenovo; QTY=1; PRICE=42000.50
```

Формат:

```text
ART-0000; Назва товару; QTY=Кількість; PRICE=Ціна
```

## Використані можливості Java

У роботі використано:

- `String.trim()`;
- `String.replaceAll()`;
- `Pattern`;
- `Matcher`;
- `matcher.group()`;
- `Integer.parseInt()`;
- `Double.parseDouble()`;
- `StringBuilder`;
- `Files.readAllLines()`.

## Основні можливості програми

Програма:

- читає записи з текстового файлу;
- нормалізує зайві пробіли;
- перевіряє формат запису;
- перевіряє артикул товару;
- вилучає числові поля;
- перетворює рядки на об’єкти `ProductOrder`;
- рахує коректні й некоректні записи;
- обчислює загальну суму;
- формує текстовий звіт.

## Запуск

Запустити програму можна через клас:

```text
Main.java
```

Запуск тестів:

```bash
mvn test
```

## Тестування

У роботі є тести для перевірки:

- нормалізації тексту;
- розбору коректного запису;
- відхилення некоректного запису;
- підрахунку коректних і некоректних рядків;
- формування звіту;
- запуску `Main`.

## Висновок

У лабораторній роботі реалізовано обробку текстових записів інтернет-магазину.

Програма використовує базові операції `String`, регулярні вирази через `Pattern` і `Matcher`, перетворює рядки на об’єкти та формує підсумковий звіт за допомогою `StringBuilder`.
