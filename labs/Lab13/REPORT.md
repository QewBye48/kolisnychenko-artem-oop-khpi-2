# Лабораторна робота №13

## Тема

Обробка тексту і регулярні вирази в Java.

## Варіант

Варіант 5 — інтернет-магазин.

## Суть задачі

Потрібно реалізувати консольну Java-програму для обробки текстових записів інтернет-магазину.

Програма повинна зчитувати дані з текстового файлу, очищувати рядки, перевіряти формат записів, вилучати потрібні поля за допомогою регулярного виразу та перетворювати текстові записи на об'єкти предметної області.

Після обробки програма повинна сформувати підсумковий звіт або чек.

---

## Що реалізовано

У роботі реалізовано:

- модель предметної області;
- текстовий файл із вхідними даними;
- зчитування даних із текстового файлу;
- базові операції класу `String`;
- нормалізацію текстових рядків;
- регулярний вираз для перевірки формату запису;
- використання `Pattern` і `Matcher`;
- вилучення груп із регулярного виразу;
- перетворення рядків на об'єкти;
- формування звіту через `StringBuilder`;
- демонстраційну програму `Main`;
- модульні тести JUnit Jupiter.

---

## Класи проєкту

У проєкті реалізовано такі класи:

- `ProductOrder` — модель одного товарного запису;
- `OrderReport` — модель підсумкового звіту;
- `OrderTextProcessor` — сервіс для обробки тексту;
- `Main` — демонстраційний запуск програми.

---

## Клас `ProductOrder`

Клас `ProductOrder` описує один запис про товар в інтернет-магазині.

Поля класу:

- `article` — артикул товару;
- `productName` — назва товару;
- `quantity` — кількість товару;
- `price` — ціна одного товару.

Клас також містить метод:

```java
getTotalPrice()
```

Метод обчислює повну суму за товар:

```text
кількість * ціна
```

---

## Клас `OrderReport`

Клас `OrderReport` описує підсумок обробки текстових записів.

Поля класу:

- `validRecords` — кількість коректних записів;
- `invalidRecords` — кількість некоректних записів;
- `totalAmount` — загальна сума замовлення.

Цей клас використовується для збереження результатів аналізу вхідного файлу.

---

## Клас `OrderTextProcessor`

Клас `OrderTextProcessor` виконує основну логіку лабораторної роботи.

Він відповідає за:

- нормалізацію рядків;
- перевірку формату запису;
- розбір одного рядка;
- перетворення рядка на об'єкт `ProductOrder`;
- підрахунок коректних і некоректних записів;
- обчислення загальної суми;
- формування підсумкового звіту.

## Вхідний файл

Вхідні дані зберігаються у файлі:

```text
src/main/resources/orders.txt
```

Приклад вмісту файлу:

```text
ART-1001; Ноутбук Lenovo; QTY=1; PRICE=42000.50
ART-1002; Миша Logitech; QTY=2; PRICE=850.00
ART-1003; Клавіатура HyperX; QTY=1; PRICE=3200.00
ART-1004; Монітор Samsung; QTY=1; PRICE=7800.99
BAD-12; Некоректний товар; QTY=1; PRICE=100.00
ART-1005; Навушники Logitech; QTY=2; PRICE=2500.00
ART-1006; USB кабель; QTY=3; PRICE=150.75
```

Файл містить як коректні, так і некоректні записи.

Це потрібно для демонстрації перевірки формату та обробки помилкових рядків.

---

## Формат запису

Коректний запис має такий формат:

```text
ART-0000; Назва товару; QTY=Кількість; PRICE=Ціна
```

Приклад коректного запису:

```text
ART-1001; Ноутбук Lenovo; QTY=1; PRICE=42000.50
```

Приклад некоректного запису:

```text
BAD-12; Некоректний товар; QTY=1; PRICE=100.00
```

Цей запис є некоректним, тому що артикул не відповідає формату `ART-0000`.

---

## Регулярний вираз

Для перевірки та розбору рядка використовується регулярний вираз:

```java
^(ART-\d{4});\s*(.+?);\s*QTY=(\d+);\s*PRICE=(\d+(?:\.\d{1,2})?)$
```

Він перевіряє:

- артикул товару у форматі `ART-0000`;
- назву товару;
- кількість товару;
- ціну товару.

Групи регулярного виразу:

1. артикул товару;
2. назва товару;
3. кількість;
4. ціна.

---

## Використання `String`

У роботі використано базові операції класу `String`.

Метод нормалізації рядка:

```java
public static String normalizeText(String line) {
    if (line == null) {
        return "";
    }

    return line.trim().replaceAll("\\s+", " ");
}
```

У цьому методі:

- `trim()` прибирає зайві пробіли на початку і в кінці рядка;
- `replaceAll("\\s+", " ")` замінює декілька пробілів одним пробілом.

---

## Використання `Pattern` і `Matcher`

Для роботи з регулярним виразом використано класи:

```java
Pattern
Matcher
```

Приклад розбору рядка:

```java
Matcher matcher = ORDER_PATTERN.matcher(line);

if (!matcher.matches()) {
    throw new IllegalArgumentException("Некоректний запис товару: " + rawLine);
}

String article = matcher.group(1);
String productName = matcher.group(2).trim();
int quantity = Integer.parseInt(matcher.group(3));
double price = Double.parseDouble(matcher.group(4));
```

Тут `matcher.group()` використовується для вилучення окремих частин рядка.

---

## Використання `StringBuilder`

Для формування підсумкового звіту використано `StringBuilder`.

Він потрібен для зручного поетапного створення багаторядкового тексту.

Приклад:

```java
StringBuilder builder = new StringBuilder();

builder.append("Звіт інтернет-магазину\n");
builder.append("Коректних записів: ").append(report.getValidRecords()).append('\n');
builder.append("Некоректних записів: ").append(report.getInvalidRecords()).append('\n');
builder.append("Загальна сума: ").append(report.getTotalAmount()).append(" грн\n");
```
