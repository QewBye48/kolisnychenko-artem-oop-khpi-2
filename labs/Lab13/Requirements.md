Лабораторна робота №13 повинна містити:

- модель предметної області;
- текстовий файл із вхідними даними;
- зчитування даних із текстового файлу;
- базові операції класу `String`;
- використання `StringBuilder` для формування звіту;
- щонайменше один регулярний вираз;
- використання `Pattern` і `Matcher`;
- вилучення даних із рядка через групи регулярного виразу;
- перетворення текстових записів на об'єкти предметної області;
- демонстраційну програму `Main`;
- модульні тести для ключової логіки текстової обробки.
