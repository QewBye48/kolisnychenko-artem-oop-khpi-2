# Лабораторна робота №9

## Тема

Узагальнення Generics в Java.

## Варіант

Варіант 5 — медичні записи.

## Мета роботи

Мета роботи — навчитися використовувати узагальнені типи в Java, створювати типобезпечні generic-класи і generic-методи, а також застосовувати обмеження параметрів типів.

У роботі потрібно показати:

- generic-клас;
- generic-метод;
- обмеження параметра типу;
- використання generic-компонента у двох конкретизаціях;
- відсутність сирих типів;
- типобезпечний клієнтський код;
- юніт-тести.

## Опис предметної області

У роботі реалізовано просту модель медичних записів.

У моделі є:

- пацієнт;
- візит до лікаря;
- рецепт.

Пацієнт може мати медичні візити і рецепти. Для збереження медичного запису разом із додатковою інформацією використовується generic-клас `MedicalRecord<TEntity, TMeta>`.

---

## Класи предметної області

### `Patient`

Клас описує пацієнта.

Поля:

- `patientId` — ідентифікатор пацієнта;
- `fullName` — ПІБ пацієнта;
- `age` — вік пацієнта.

---

### `Visit`

Клас описує медичний візит.

Поля:

- `visitId` — ідентифікатор візиту;
- `patient` — пацієнт;
- `visitDate` — дата візиту;
- `doctorName` — ім'я лікаря.

Клас реалізує:

```java
Comparable<Visit>
```

Це потрібно для порівняння візитів за датою.

---

### `Prescription`

Клас описує рецепт.

Поля:

- `prescriptionId` — ідентифікатор рецепта;
- `patient` — пацієнт;
- `medicineName` — назва препарату;
- `doseMg` — доза препарату;
- `days` — тривалість лікування в днях.

Клас реалізує:

```java
Comparable<Prescription>
```

Це потрібно для порівняння рецептів за тривалістю лікування.

---

## Generic-клас

У роботі реалізовано generic-клас:

```java
MedicalRecord<TEntity, TMeta>
```

Він використовується для типобезпечного зв'язування медичного об'єкта з додатковими метаданими.

Поля:

```java
private final TEntity entity;
private final TMeta metadata;
```

Приклади конкретизації:

```java
MedicalRecord<Visit, String> visitRecord =
        new MedicalRecord<>(visit1, "Плановий візит");
```

```java
MedicalRecord<Prescription, Integer> prescriptionRecord =
        new MedicalRecord<>(prescription1, 1);
```

У першому випадку основним об'єктом є `Visit`, а метаданими є `String`.

У другому випадку основним об'єктом є `Prescription`, а метаданими є `Integer`.

---

## Generic-метод

У роботі реалізовано generic-метод:

```java
public static <T extends Comparable<? super T>> T findMaximum(List<T> items)
```

Метод знаходить максимальний елемент у списку.

Обмеження:

```java
T extends Comparable<? super T>
```

означає, що метод може працювати тільки з тими типами, які можна порівнювати.

Метод використовується для:

- пошуку найпізнішого візиту;
- пошуку рецепта з найбільшою тривалістю;
- пошуку максимального числа у списку `Integer`.

---

## Чому generics доречні

Generic-клас `MedicalRecord<TEntity, TMeta>` є доречним, тому що медичний запис може зберігати різні типи об'єктів:

- візит;
- рецепт;
- інший медичний запис.

При цьому метадані також можуть мати різний тип:

- текстовий опис;
- номер пріоритету;
- статус.

Без generics довелося б використовувати `Object`, що призвело б до втрати інформації про типи і необхідності приведення типів.

Generics дозволяють зберегти типобезпеку на етапі компіляції.

## Висновок

У роботі було створено просту модель медичних записів.

Generic-клас `MedicalRecord<TEntity, TMeta>` дозволяє типобезпечно зв'язувати медичну сутність із метаданими. Один і той самий клас можна використовувати для різних типів даних без дублювання коду.

Generic-метод `findMaximum()` дозволяє працювати з різними типами, якщо вони підтримують порівняння. Обмеження `T extends Comparable<? super T>` робить метод безпечним і змістовним.

Таким чином, generics у цій роботі використані не формально, а для покращення типобезпеки та повторного використання коду.
