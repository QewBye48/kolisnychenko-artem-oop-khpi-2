# Лабораторна робота №12

## Тема

Stream API в Java.

## Варіант

Варіант 5 — медіатека.

## Суть задачі

Потрібно реалізувати консольну Java-програму для роботи з медіатекою.

Програма повинна показати використання Stream API для обробки колекцій даних: фільтрації, перетворення, сортування, підрахунку, групування та побудови текстового звіту.

## Що реалізовано

У проєкті реалізовано такі класи:

- `Movie` — клас фільму;
- `Episode` — клас епізоду подкасту;
- `Podcast` — клас подкасту;
- `MediaLibrary` — сервіс для обробки медіатеки через Stream API;
- `Main` — демонстраційний запуск програми.

## Основні можливості програми

Програма дозволяє:

- створити список фільмів;
- створити список подкастів;
- отримати всі фільми;
- знайти фільми за жанром;
- отримати назви фільмів, відсортовані за рейтингом;
- підрахувати кількість фільмів певного жанру;
- згрупувати фільми за жанром;
- знайти середній рейтинг фільмів;
- знайти найдовший фільм;
- отримати всі назви епізодів подкастів;
- сформувати текстовий звіт за фільмами;
- порівняти імперативний підхід і Stream API.

## Використані Stream API операції

У роботі використано такі операції Stream API:

- `filter()` — відбір фільмів за жанром;
- `map()` — перетворення об'єктів у назви;
- `sorted()` — сортування фільмів за рейтингом;
- `count()` — підрахунок кількості фільмів;
- `toList()` — збирання результату в список;
- `collect()` — збирання результату через колектори;
- `groupingBy()` — групування фільмів за жанром;
- `flatMap()` — отримання всіх епізодів з усіх подкастів;
- `max()` — пошук найдовшого фільму;
- `joining()` — побудова текстового звіту.

## Приклади методів сервісу

У класі `MediaLibrary` реалізовано такі методи:

```java
getMoviesByGenre(String genre)
```

Повертає список фільмів певного жанру.

```java
getMovieTitlesSortedByRating()
```

Повертає назви фільмів, відсортовані за рейтингом.

```java
countMoviesByGenre(String genre)
```

Підраховує кількість фільмів певного жанру.

```java
groupMoviesByGenre()
```

Групує фільми за жанром.

```java
getAverageMovieRating()
```

Обчислює середній рейтинг фільмів.

```java
getLongestMovie()
```

Повертає найдовший фільм через `Optional`.

```java
getAllEpisodeTitles()
```

Повертає назви всіх епізодів усіх подкастів.

```java
buildMovieReport()
```

Формує текстовий звіт за фільмами.

## Демонстрація роботи

У класі `Main` створюються тестові дані:

- список фільмів;
- список епізодів;
- список подкастів.

Після цього створюється об'єкт `MediaLibrary`, через який демонструється робота основних stream-методів.

Запустити програму можна через клас:

## Висновок

У лабораторній роботі було реалізовано просту медіатеку з використанням Stream API.

Stream API дозволив обробляти колекції у декларативному стилі: фільтрувати дані, перетворювати об'єкти, сортувати, групувати, підраховувати та формувати текстові звіти.

Робота показує, що Stream API робить код коротшим і зрозумілішим у задачах обробки колекцій.
