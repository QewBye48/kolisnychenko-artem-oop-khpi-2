# Вимоги до програми
## Варіант 5 — Способи доставки

## Загальні вимоги

1. Програма повинна реалізовувати просту систему розрахунку вартості різних способів доставки.
2. Програма повинна бути написана мовою Java.
3. Програма повинна використовувати принципи об'єктно-орієнтованого програмування.
4. У програмі має бути продемонстровано поліморфізм через абстрактний базовий клас.
5. Інтерфейси у цій лабораторній роботі не використовуються.

---

## Функціональні вимоги

1. Система повинна підтримувати декілька способів доставки.
2. У програмі повинні бути реалізовані такі типи доставки:
    - кур'єрська доставка;
    - доставка до поштомата;
    - доставка дроном.
3. Кожен спосіб доставки повинен мати спільні дані:
    - номер замовлення;
    - адресу доставки;
    - базову вартість доставки.
4. Кожен конкретний спосіб доставки повинен мати власні додаткові дані:
    - `CourierDelivery` — відстань доставки в кілометрах;
    - `ParcelLockerDelivery` — номер поштомата;
    - `DroneDelivery` — вагу посилки.
5. Кожен спосіб доставки повинен по-своєму розраховувати кінцеву вартість доставки.
6. Програма повинна виводити коротку інформацію про доставку.
7. Програма повинна демонструвати поліморфний виклик методу розрахунку вартості через базовий тип `DeliveryMethod`.

---

## Вимоги до структури

1. Програма повинна містити такі класи:
    - `DeliveryMethod` — абстрактний базовий клас;
    - `CourierDelivery` — кур'єрська доставка;
    - `ParcelLockerDelivery` — доставка до поштомата;
    - `DroneDelivery` — доставка дроном;
    - `Main` — клас для демонстрації роботи програми.

2. Абстрактний клас `DeliveryMethod` повинен містити спільний стан:
    - `orderId`;
    - `address`;
    - `basePrice`.

3. Абстрактний клас `DeliveryMethod` повинен містити спільну поведінку:
    - метод `getInfo()` для отримання короткої інформації про доставку;
    - гетери для спільних полів.
