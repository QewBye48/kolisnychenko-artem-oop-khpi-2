# Облік спортивних секцій університету (Лабораторна робота №4) – Тестування за допомогою TestNG

## Опис проєкту
Даний проєкт є продовженням розробки системи обліку університетського спортивного клубу. Головною метою цієї лабораторної роботи є міграція та розширення модульних тестів із використанням фреймворку **TestNG** замість JUnit Jupiter. 

Проєкт демонструє побудову керованого тестового набору, використання анотацій життєвого циклу, групування тестів, параметризацію через зовнішні джерела даних та збір метрик покриття коду (JaCoCo).

Проєкт створено в рамках лабораторної роботи №4 з дисципліни **Об'єктно-орієнтоване програмування**.

---

## Особливості тестування (TestNG)
Відповідно до вимог переходу на TestNG, у проєкті реалізовано наступні концепції:

1. **Фікстури (`@BeforeMethod`):**
   * Використовуються для підготовки чистого стану перед кожним тестом (наприклад, ініціалізація `SportsClub` та базових об'єктів), що гарантує відтворюваність та ізольованість перевірок.
2. **Параметризація (`@DataProvider`):**
   * Застосована для перевірки створення сутностей (наприклад, класу `Student`) на різних наборах вхідних даних без дублювання тестового коду.
3. **Групування тестів (`groups`):**
   * **`smoke`**: Швидкі поверхневі перевірки (ініціалізація класів, базові `toString`).
   * **`domain`**: Глибокі перевірки бізнес-логіки системи (реєстрація студентів, створення секцій).
   * **`negative`**: Сценарії, що перевіряють стійкість системи до некоректних даних (очікувані винятки, такі як `NullPointerException` чи `IllegalStateException`).
4. **Керування запуском (`testng.xml`):**
   * Склад запуску тестів явно винесено у конфігураційний файл `testng.xml`, який об'єднує всі тестові класи та визначає, які групи підлягають виконанню.

## Структура проєкту

Проєкт має стандартну структуру Maven і поділяється на основний код та тести:

* `src/main/java/ua/khpi/oop/lab04/` — містить предметну модель системи:
  * `SportsClub`, `Enrollment`, `SportSection`, `Student`, `Coach`, `Schedule`.
* `src/test/java/ua/khpi/oop/lab04/` — містить тестові класи TestNG:
  * `SportsClubTest`, `StudentTest` (з DataProvider), `SportSectionTest`, `CoachTest`, `ScheduleTest`, `EnrollmentTest`.
* `testng.xml` — конфігурація TestNG для запуску груп та класів.
* `pom.xml` — конфігурація Maven (налаштування плагінів Surefire для запуску TestNG та JaCoCo для звіту про покриття).

## Як запустити тести

1. Відкрийте термінал у кореневій папці проєкту (`Lab04`).
2. Для компіляції та запуску всього набору тестів (через `testng.xml`) виконайте:
   ```bash
   mvn clean test
3. Для запуску тестів та одночасної генерації звіту про покриття коду (JaCoCo) виконайте:
  mvn clean verify
