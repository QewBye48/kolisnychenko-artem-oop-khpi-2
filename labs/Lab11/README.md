# Лабораторна робота №11

## Тема

Collections Framework в Java.

## Варіант

Варіант 5 — ігровий профіль.

## Суть задачі

Потрібно реалізувати консольну Java-програму для роботи з ігровим профілем гравця.

Програма повинна показати використання стандартних колекцій Java для зберігання, пошуку, перегляду та видалення даних.

У роботі використано стандартні колекції `List`, `Set` і `Map`. Для ЛР11 потрібно використати щонайменше дві різні стандартні колекції Java, реалізувати сервіс або реєстр, а також показати базові операції над даними. :contentReference[oaicite:0]{index=0}

## Що реалізовано

У проєкті реалізовано такі класи:

- `Player` — клас гравця;
- `GameItem` — клас ігрового предмета;
- `Achievement` — клас досягнення;
- `GameProfileService` — сервіс для роботи з профілем гравця;
- `Main` — демонстраційний запуск програми.

## Використані колекції

У класі `GameProfileService` використано:

```java
List<GameItem>
```

Ця колекція зберігає предмети гравця у порядку додавання.

```java
Set<Achievement>
```

Ця колекція зберігає унікальні досягнення гравця і не дозволяє додавати дублікати.

У класі `Main` також використано:

```java
Map<String, String>
```

Вона потрібна для демонстрації роботи з парами ключ-значення та обходу через `entrySet()`.

## Основні можливості програми

Програма дозволяє:

- створити гравця;
- додати предмети;
- знайти предмет за назвою;
- видалити предмет;
- додати досягнення;
- не допустити дублювання досягнень;
- переглянути всі предмети;
- переглянути всі досягнення;
- вивести інформацію про профіль гравця.

## Запуск програми

Запустити програму можна через клас:

```text
Main.java
```

Або через Maven:

```bash
mvn exec:java -Dexec.mainClass="ua.khpi.oop.lab11.demo.Main"
```

## Запуск тестів

```bash
mvn test
```

## Тестування

У роботі є тести для перевірки:

- додавання предметів;
- пошуку предмета;
- видалення предмета;
- додавання досягнень;
- заборони дублювання досягнень;
- запуску `Main` без помилок.

## Висновок

У цій лабораторній роботі було показано використання стандартних колекцій Java на прикладі ігрового профілю.

`List` використано для зберігання предметів, а `Set` — для зберігання унікальних досягнень. Це дозволяє зручно працювати з даними та обирати колекцію відповідно до задачі.
