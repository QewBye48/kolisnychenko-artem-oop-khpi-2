note right of GameProfileService
Collections Framework:
- ArrayList<GameItem>
- LinkedHashSet<Achievement>

List зберігає предмети
у порядку додавання.

Set зберігає унікальні
досягнення без дублікатів.
end note

note right of Achievement
equals() і hashCode()
реалізовані за title,
щоб Set коректно
визначав дублікати.
end note
