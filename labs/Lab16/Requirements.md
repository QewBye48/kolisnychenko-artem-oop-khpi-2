Лабораторна робота №16 виконується як окремий Java-проєкт із JNI та CI.

Що реалізовано:
- Java-реалізація операції підрахунку кількості елементів, більших за поріг;
- native-реалізація тієї самої операції через JNI;
- header-файл у каталозі native-headers;
- C++ файл із JNI-функцією;
- юніт-тести для Java-, native- і порівняльного сценаріїв;
- Maven-конфігурація проєкту;
- GitHub Actions workflow.
